# LingoDash — 英語学習ダッシュボード（個人用 PWA）

https://lingodash-eta.vercel.app/ のブラッシュアップ版。タイ語学習ダッシュボード（`../thai-learning`）と同じ構成
（Vite + React + TypeScript + Tailwind、PWA、進捗は IndexedDB）で、**発音 → 文法 → インプット → アウトプット** の順に進む
12 週カリキュラムと、現在地を測る**レベルチェック**を中心に据えた。

学習法の原則（インプット 8 : アウトプット 2、日本語字幕を使わない、シャドーイングは録音、前置詞はイメージで、
500 回聞く素材を決める、反射的に出るまで練習する、自分について語れる情報をストックする…）はアプリ内「計画 → 学習法」にまとめてある。

## 使い方（ローカル）

```bash
cd lingodash
npm install
npm run dev        # http://localhost:5174
```

- `npm run build` … 本番ビルド（`dist/`）。`npm run preview` で確認
- `npm run typecheck` … 型チェック
- `npm run content:check` … コンテンツ JSON の整合性チェック（ID 重複・参照切れ・カリキュラムの割り当て漏れ）

## コンテンツの追加・修正

`src/content/*.json` を編集するだけ。編集後に `npm run content:check`。

- `items.json` … 語彙・フレーズ（`id` は変えない。進捗は id で紐付く）。前置詞は `image` に図の種類、語源は `parts`
- `scenes.json` … テーマ　／ `phonics.json` … 発音記号・最小対・フォニックス　／ `grammar.json` … 文法ユニット
- `roleplays.json` … 台本（`kind: partner | you | branch | end`）　／ `curriculum.json` … 12 週の割り当て
- `resources.json` … 教材　／ `prompts.json` … 自分について・反射ドリル・ライティングのお題　／ `materials.json` … シャドーイング素材・ディクテーション文
- `levelcheck.json` … レベルチェックの問題（採点ロジックは `src/lib/levelcheck.ts`）

## 音声

既定は端末の Web Speech API（英語）。設定でアクセントと声を選べる。iPhone は「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 英語」で拡張音声を入れると自然になる。
事前生成 mp3 に差し替えるには `public/audio/<itemId>.mp3` を置き、`items.json` に `"audio": "<itemId>.mp3"` を足す。

## Vercel へのデプロイ

既存の Vercel プロジェクト `lingodash`（lingodash-eta.vercel.app）は CLI から直接デプロイされていて Git と繋がっていない。
このフォルダをデプロイするには、プロジェクトの **Settings → Git** でこのリポジトリ（KeisukeKirby/stock-dashboard）を接続し、
**Root Directory** を `lingodash` にする（Framework: Vite、Build `npm run build`、Output `dist`。`vercel.json` に記載済み）。
以後は `git push` で自動デプロイ。

CLI の場合：

```bash
cd lingodash
npx vercel link      # 既存の lingodash プロジェクトを選ぶ
npx vercel --prod
```

## 進捗データ

端末の IndexedDB（`lingodash`）に保存。設定画面から JSON でエクスポート／インポート（マージ or 置き換え）。
