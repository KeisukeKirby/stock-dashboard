# LingoDash 設計メモ

## 学習法 → 機能の対応

| 原則 | 機能 |
| --- | --- |
| まず発音から。発音記号・フォニックス・音の区別 | 発音トレーナー（IPA 25 / フォニックス 12 / 最小対 22）、今日のメニューの ① は必ず最小対、レベルチェックの聞き分けセクション |
| シャドーイングを録音 | RecorderPanel（お手本 → 録音 → 聞き比べ → 認識チェック）を新アイテム・文法・シャドーイング・ロールプレイ・スピーキングに組み込み |
| 前置詞は日本語を介さずイメージで | PrepositionFigure（SVG 22 種）。一覧も図を先に表示 |
| 1 万語には語源の知識 | roots テーマ（接頭辞・語幹・接尾辞を部品として表示）、Week 9–10 |
| 発音の次は文法。例文を声に出す。時制・助動詞 | 文法 12 ユニット、ドリルは日本語 → 声に出す → 正解 → 録音 |
| 実践的状況のストック不足 | 店舗・接客／ビジネス・会議／雑談と文化（行動様式メモ）／ロールプレイ 5 本 |
| 英語を学ぶ → 英語で学ぶ | academic テーマ、Week 11–12（MIT OCW・教科書）、教材一覧の「英語で学ぶ」カテゴリ |
| インプット 8 : アウトプット 2 | 画面・ステップごとに IN/OUT を分類して分単位で記録。ホームと記録に配分を表示 |
| スピーキング最重要。反射速度。撮影してダブルチェック | SpeakRunner の 3 秒カウントダウン、反射ドリル、録音数の記録 |
| 自分について語れる情報をストック | About-me 20 問（テキスト保存・反射 OK フラグ） |
| ライティングは口に出す感覚で。主題を 1 文で | WriteRunner（タイマー・語数・1 文要約・接続詞チェック） |
| リスニング最難関。字幕付き → なし。ディクテーション。500 回 | ディクテーション（単語採点）、500 回カウンター、カリキュラムの字幕段階 |
| 好きなテーマを読む・楽しむ・使ってこそ | 教材 35 件とステータス、Week 12 の「実際に使う」タスク |

## データ

- content: `src/content/*.json`（読み取り専用）
- progress: IndexedDB `lingodash` v1 — `cards`（SRS）, `dailyLog`（日別。IN/OUT 分・各クイズ・録音・語数）, `settings`, `meta`（plan, level, levelHistory）, `journal`（ライティング・ディクテーション）, `kv`（aboutme:*, shadow:*, resource:*, grammar:*, task:*）
- レベルチェックの採点: `src/lib/levelcheck.ts`。語彙は頻度帯ラダー、文法・リスニングはレベル別ラダー、総合は客観 7 : 主観 3

## 今日のメニューの組み立て（`src/lib/session.ts`）

週のフェーズ（発音 / 文法 / インプット / アウトプット）と設定のメニュー長で、各ステップの量を変える。
新アイテムはカリキュラムの「現在の週まで」で未導入のものを週順に（繰り越し）。文法は今週のユニットを日替わりで。
