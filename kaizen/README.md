# 業務改善マニュアル

各スタッフ・セクションの既存の業務プロセスを最適化・効率化して生産性を上げるための改善マニュアル。
ページ上で内容を書き足して全員に共有でき、A4 縦でそのまま PDF 化できます。

在庫ダッシュボードとは独立した Vercel プロジェクトです（**Root Directory を `kaizen` に設定**）。

## 使い方

- **イラスト版 / 文章版**: 右上の「イラスト / 文章」で切り替え（初期表示はイラスト版、`?view=text` で文章版）。イラスト版はタイ人スタッフ向けの図解で、項目ごとに主役のイラスト・「これまで → これから」・手順のピクトグラム・チェックを並べ、文章は短い補足として付けています。イラストと文言は `infographic.js` に 3 言語でまとめてあり、文章版（kaizen.md など）とは別管理です。「編集」を押すと文章版に切り替わって編集画面が開きます
- **冊子（プレゼン形式）**: イラスト版は部門ごとの冊子です。1 枚目に 6 冊（経理・物流・在庫倉庫 QC・HR・EC・全体）が並び、クリックするとその冊子の横長スライド（1280 × 720）が開きます。← → キー・画面下のボタン・スワイプでページ送り、「全画面」で発表用に。URL は `#/b2/3`（第 2 章の 3 ページ目）の形で、そのページを直接開けます。イベント手順書（付録）は物流の冊子の最後に入っています
- **文章版との関係（作業メモ）**: 2026-11 時点で、イラスト版（`infographic.js`）にだけ部門別の改善提案（経理の①〜⑦、店舗補充の配送曜日、イベント手順のチェック表など）が入っています。文章版（`kaizen.md` / `kaizen.en.md` / `kaizen.th.md`）への反映は、依頼者から「完成」の指示が出てから行います

- **言語**: 右上の「日本語 / English / ไทย」で切り替え。選んだ言語はブラウザに記憶され、`?lang=en` のように URL でも指定できます（共有するときは `https://kaizen-manual.vercel.app/?lang=th` など）。初回はブラウザの言語設定で自動選択。**本文は言語ごとに別**で、編集・保存・保存履歴もいま表示中の言語だけに効きます（日本語を直しても英語・タイ語は自動では変わりません）

- **閲覧**: URL を開くだけ。他の人が保存した内容は、画面に戻ったときに自動で取り込まれます
- **編集**: 右上「編集」→ 左にテキスト、右にプレビュー。「保存して共有」（Ctrl+S）で同じ URL を開いている全員に反映。書き方は編集画面の「書き方」に一覧
- **PDF 化**: 右上「PDF にする」→ ブラウザの印刷で「PDF に保存」（背景のグラフィックをオン）。イラスト版は横長スライド 1 枚 = 1 ページで、1 枚目（冊子一覧）で押すと全冊、冊子を開いて押すとその冊子だけが PDF になります。文章版は A4 縦です。編集中に押すと、いま書いている内容で PDF になります
- **控え**: 「.md を保存」でテキストをダウンロード、「.md を開く」で戻す。「保存履歴」から直近 30 回の保存を呼び戻せます

## Vercel の設定

1. 新しいプロジェクトを作り、このリポジトリを選んで **Root Directory = `kaizen`**（Framework Preset は Other、ビルドコマンドなし）
2. **Storage → Upstash for Redis** を作成（または既存のものを）このプロジェクトに接続（環境変数 `KV_REST_API_URL` / `KV_REST_API_TOKEN` が入ります）。未接続のときは共有保存にならず、各自のブラウザにだけ保存されます
3. 編集を制限する場合は環境変数 `KAIZEN_EDIT_KEY` に任意の文字列を設定して再デプロイ。保存時にその編集キーを求められます（閲覧は誰でも可）

## ファイル

```
index.html      ページ（閲覧・編集・PDF）
kaizen.css      画面と A4 印刷のスタイル
kaizen-md.js    本文テキスト（Markdown 風）の解析
infographic.js  イラスト版（SVG のイラストと 3 言語の文言）
kaizen.js       読み込み・描画・編集・保存
kaizen.md       共有保存が空のときに表示する初期本文（日本語）
kaizen.en.md    同（英語）
kaizen.th.md    同（タイ語）
api/kaizen.js   共有保存 API（Upstash Redis。?lang=ja|en|th で言語ごとに別のキー）
vercel.json
```

配布用の PDF をコマンドで作る（Playwright の Chromium を使用）:

```bash
node ../scripts/build_kaizen_pdf.mjs ../out/kaizen.pdf https://<公開 URL>/   # 公開中の内容から
node ../scripts/build_kaizen_pdf.mjs ../out/kaizen.pdf                        # この kaizen.md から
node ../scripts/build_kaizen_pdf.mjs ../out/kaizen_th.pdf th                  # タイ語（en で英語）
```
