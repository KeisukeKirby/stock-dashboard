Write # [Appendix] Title for an appendix (A, B, C).
A line with only ==== starts a new page.

  - Second level (indent 2 spaces)

| Heading | Heading |

| Text | Text |

# ชื่อบท
> คำอธิบายสั้น ๆ ของบท

## ชื่อหัวข้อ
เนื้อหา ใช้ **ตัวหนา** ได้

### หัวข้อย่อย

บทและหัวข้อจะใส่เลขให้อัตโนมัติ (บทที่ N, N.M) และสร้างสารบัญให้เอง
เขียน # [ภาคผนวก] ชื่อ เพื่อทำภาคผนวก (A, B, C)
บรรทัดที่มีแค่ ==== คือขึ้นหน้าใหม่

ส่วนประกอบของเนื้อหา

- รายการแบบจุด
  - ระดับที่ 2 (เว้น 2 ช่อง)
1. รายการแบบตัวเลข

| หัวตาราง | หัวตาราง |
|---|---|
| เนื้อหา | เนื้อหา |

:::proposal
เดิม: เคยทำอย่างไร
ปัญหา: เกิดปัญหาอะไร
ใหม่: จะทำอย่างไรต่อจากนี้
ตรวจสอบ: ดูจากอะไรว่าได้ผล
:::   ← บรรทัดที่ไม่เขียนจะไม่แสดง

:::flow
- จันทร์ ช่วงเช้า: ทำรายการเติมสินค้า
- จันทร์ ช่วงบ่าย: ส่งของ
:::

:::check เช็กลิสต์ปิดร้าน
- ปิดยอด POS
:::

:::kv
ผู้รับผิดชอบ / ความถี่: ผู้จัดการสาขา ทุกวัน
:::

แต่ละภาษามีเนื้อหาแยกกัน และจะบันทึกเฉพาะภาษาที่แสดงอยู่ บันทึกด้วย Ctrl+S (Mac ใช้ ⌘S) ได้เช่นกัน
